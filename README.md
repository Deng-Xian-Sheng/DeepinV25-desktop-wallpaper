## 如何运行它

1、克隆仓库

2、手动通过 Deepin 的 “控制中心” 将仓库里面的 `透明壁纸.png` 设为你的壁纸

3、`python video_wallpaper.py`

## 它实现了什么？

1、在 Deepin V25 上实现了视频壁纸

2、提供了 4 个 macOS 的视频壁纸

3、视频壁纸会随着时间自动更换

4、节能播放策略，在这些情况下不会播放：锁屏、熄屏、持续5分钟未做键盘鼠标操作、当前虚拟桌面（或者叫工作区）有任何（除了mpv和桌面窗口之外的）未被最小化或者隐藏窗口

5、显示视频壁纸时，桌面图标可正常呈现🚀

## 依赖？

依赖一些命令行工具，需要安装的可能有：`wmctrl`，其他的 Deepin 自带。

脚本会在运行之前检查这些依赖。
